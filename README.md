\# Practica Final DevOps CI/CD



\## Objetivo



Crear una aplicación web Hola Mundo utilizando Python y Flask,

automatizando las pruebas, la construcción de Docker, la publicación

de la imagen en Docker Hub y el despliegue en producción mediante

GitHub Actions y Render.



\## Tecnologías utilizadas



\- Python 3.12

\- Flask

\- Pytest

\- Gunicorn

\- Docker

\- Docker Hub

\- GitHub

\- GitHub Actions

\- Render
